Политика конфиденциальности

Редакция от 11 сентября 2026

1. Общие положения

1.1. Настоящая Политика регулирует обработку информации при использовании сайта и сервисов магазина «Гарант» (далее — «Сервис»).

1.2. Используя Сервис, Пользователь соглашается с настоящей Политикой.

1.3. При несогласии Пользователь обязан прекратить использование Сервиса.

2. Собираемые данные

2.1. Сервис собирает минимально необходимые данные:

  • фамилия, имя (при оформлении заказа);
  • контактный номер телефона;
  • адрес электронной почты;
  • сведения о заказе (модель, память, цвет, цена);
  • техническая информация (IP-адрес подключения, данные браузера, объём трафика);
  • история взаимодействий с Сервисом.

2.2. Сервис не собирает и не хранит:

  • историю посещаемых интернет-ресурсов;
  • содержимое передаваемого трафика;
  • DNS-запросы.

2.3. Данные платёжных карт обрабатываются платёжным провайдером — Сервис их не получает и не хранит.

3. Использование данных

3.1. Собранные данные используются для:

  • предоставления и обеспечения работы Сервиса;
  • оформления, подтверждения и доставки заказа;
  • технической поддержки и связи с Пользователем;
  • предотвращения злоупотреблений;
  • исполнения требований законодательства.

4. Передача третьим лицам

4.1. Данные не продаются и не передаются третьим лицам, за исключением:

  • служб доставки и платёжных провайдеров (минимум данных для исполнения заказа);
  • случаев, предусмотренных законодательством РФ;
  • запросов уполномоченных государственных органов в установленном порядке.

5. Хранение и защита

5.1. Данные хранятся на защищённых серверах в течение срока, необходимого для целей обработки.

5.2. Администрация применяет разумные технические и организационные меры защиты.

5.3. Абсолютная безопасность данных при передаче через интернет не гарантируется.

6. Файлы cookie

6.1. Сайт может использовать файлы cookie для корректной работы интерфейса и анализа обезличенной статистики посещений.

6.2. Пользователь может отключить cookie в настройках браузера, однако это может повлиять на работу отдельных функций сайта.

7. Отказ от ответственности

7.1. Пользователь осознаёт, что передача данных через интернет сопряжена с рисками.

7.2. Администрация не несёт ответственности за:

  • утрату, кражу или разглашение данных по вине третьих лиц;
  • утрату данных вследствие действий или бездействия Пользователя;
  • перехват данных при передаче через сети общего пользования.

8. Изменения

8.1. Политика может изменяться без предварительного уведомления.

8.2. Актуальная версия публикуется на данной странице.

8.3. Продолжение использования Сервиса означает согласие с изменениями.
